# 楓之谷經典服・個人資料查詢

從本機經典版遊戲資源整理的純靜態資料庫，可離線使用，也已準備好部署到 GitHub Pages。

## 收錄功能

- 怪物掉落：查怪物、掉落物、地圖與相關任務。
- 道具圖鑑：顯示消耗品、卷軸、任務道具、其他／設置／點數道具的說明與效果。
- 裝備能力：顯示圖示、需求、基礎能力、攻速、升級次數、價格與已知取得方式。
- 任務流程：顯示接取條件、目標、回報 NPC、物品變動、獎勵，以及可逐項跳轉的完整前後任務鏈。
- 職業配點：19 套一、二轉推薦，涵蓋五大職業與 12 條二轉分支。
- 經驗計算：可分享遊戲視窗、自動尋找或手動框選 EXP 顯示區域，以本機 OCR 記錄起始／結束經驗、時間與每小時效率。
- 雙向關聯：道具／裝備、掉落怪物、任務取得與任務用途可互相跳轉。
- 閱讀介面：可切換明亮／暗色主題並記住選擇，敘述文字使用較大的閱讀尺寸。

## 本機使用

直接雙擊 `index.html` 即可，不需要後端或資料庫。

經驗計算器的畫面分享功能需要瀏覽器安全環境，建議使用已部署的 GitHub Pages HTTPS 網址；部分瀏覽器在直接開啟 `file://` 檔案時不會提供畫面分享權限。

## GitHub Pages 發佈

專案已附 `.github/workflows/pages.yml`。建立公開 GitHub 倉庫後：

1. 將本資料夾推送到倉庫的 `main` 分支。
2. 在倉庫 `Settings → Pages → Build and deployment` 選擇 `GitHub Actions`。
3. 等候 `Deploy static site to GitHub Pages` 工作完成。

網站網址通常會是 `https://<帳號>.github.io/<倉庫名稱>/`。

## 資料來源與限制

- 中文名稱、道具與任務文字：本機文字資源
- 出沒地圖與掉落物：本機 `MonsterBook`
- 道具效果：本機 `Item` WZJS
- 裝備需求與基礎能力：本機 `Equipment` WZJS
- 任務條件與獎勵：本機 `Quest Check`、`Quest Act`
- 道具圖示：本機 WZSS 圖集
- 技能名稱與效果：本機 `Skill` 文字資源；推薦順序另交叉比對社群攻略

圖鑑沒有掉落機率，任務也可能受伺服器腳本調整。遊戲名稱與美術素材的權利屬原權利人；公開散布前請自行確認遊戲條款與素材使用授權。

## 重建資料

- `tools/build_extended_data.py`：產生道具、裝備與任務資料。
- `tools/build_skill_guides.py`：以本機技能名稱校正並產生職業配點資料。
- `tools/wzjs_reader.py`：WZJS v5 讀取器。

資料重建需要 Python、UnityPy 與本機遊戲 bundle。
